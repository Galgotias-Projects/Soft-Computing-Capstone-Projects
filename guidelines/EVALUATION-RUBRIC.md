# Evaluation Rubric - 50 Marks

| Component | Marks | Evidence |
|---|---:|---|
| GitHub | 10 | structure/README 2; code 3; continuous commits 3; visible contribution 2 |
| Report | 10 | problem/data/method/implementation/results/clarity |
| Video | 10 | problem, concepts, live demo, results, clarity |
| Deployment & UI | 10 | public hosted link 2; working flow 3; usability 2; visualisation 2; reliability 1 |
| Viva & Presentation | 10 | technique 3; own code 3; results 2; communication 2 |
| **Total** | **50** | Viva marks are individual. |

**Deployment rule:** a localhost-only demonstration is not accepted for the final product. Include the public hosted link in the README and video.
